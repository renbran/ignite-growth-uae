## 🎓 By Use Case

### "I want to start developing right now"
1. Read: [VSCODE_QUICK_START.md](./VSCODE_QUICK_START.md) (2 min)
2. Get API key from https://console.hyperbolic.xyz/
3. Set environment variable
4. Run: `Tasks: Run Task` → `Dev: Frontend + MCP`
5. Start coding at http://localhost:5173

### "I want to understand the setup"
1. Read: [README_COMPLETE_SETUP.md](./README_COMPLETE_SETUP.md) (5 min)
2. Read: [VSCODE_MCP_SETUP_COMPLETE.md](./VSCODE_MCP_SETUP_COMPLETE.md) (10 min)
3. Review: [VSCODE_IMPLEMENTATION_CHECKLIST.md](./VSCODE_IMPLEMENTATION_CHECKLIST.md) (5 min)
4. Verify setup with checklist

### "I want to use the carousel"
1. Read: [NEWS_CAROUSEL_QUICK_START.md](./NEWS_CAROUSEL_QUICK_START.md) (5 min)
2. Check component: `src/components/NewsCarousel.tsx`
3. Update data: `src/config/newsConfig.ts`
4. Test on http://localhost:5173

### "I want to use AI visual reviews"
1. Read: [FRONTEND_REVIEW_MCP_SETUP.md](./FRONTEND_REVIEW_MCP_SETUP.md) (10 min)
2. Get Hyperbolic API key
3. Read: [FRONTEND_REVIEW_MCP_WORKFLOW.md](./FRONTEND_REVIEW_MCP_WORKFLOW.md) (8 min)
4. Start MCP server and begin reviews

### "I want to debug the application"
1. Read: [VSCODE_MCP_SETUP_COMPLETE.md](./VSCODE_MCP_SETUP_COMPLETE.md) - Debug section
2. Press `F5` in VS Code
3. Choose debug configuration
4. Follow Chrome DevTools workflow

### "Something's not working"
1. Check: [VSCODE_QUICK_START.md](./VSCODE_QUICK_START.md) - Troubleshooting section
2. Check: [VSCODE_MCP_SETUP_COMPLETE.md](./VSCODE_MCP_SETUP_COMPLETE.md) - Troubleshooting section
3. Verify environment: `echo $env:HYPERBOLIC_API_KEY`
4. Check file paths and permissions
5. Review task output in Terminal panel
