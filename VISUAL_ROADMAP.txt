CONNECTION DETECTION LOGIC
═══════════════════════════════════════════════════════════════════════════════

User Visits Website
       ↓
Check: navigator.connection.saveData
   ├─ TRUE  ──→ "User wants to save data"  ──→ Use 360p
   └─ FALSE ──→ Continue checking
       ↓
Check: navigator.connection.effectiveType
   ├─ "slow-2g" / "2g"  ──→ Use 360p
   ├─ "3g"              ──→ Check device type
   │   ├─ Mobile  ──→ Use 360p
   │   └─ Tablet  ──→ Use 720p
   └─ "4g"              ──→ Check device type
       ├─ Mobile  ──→ Use 720p
       ├─ Tablet  ──→ Use 720p
       └─ Desktop ──→ Use 1080p


PLAYBACK CONTROL LOGIC
═══════════════════════════════════════════════════════════════════════════════

Video Element Rendered
       ↓
Set up Intersection Observer
       ├─ Video visible → Load source
       ├─ Video visible + Mobile → Show play button
       └─ Video visible + Desktop → Auto-play (if allowed)
       ↓
Set up Visibility Listener
       ├─ Document hidden → Pause video (save battery)
       └─ Document visible → Resume video
       ↓
User Interactions
       ├─ User clicks play → Video plays
       ├─ User tabs away → Video pauses
       ├─ User returns → Video resumes
       └─ User scrolls away → Video stops (unload?)


DATA SAVINGS CALCULATION
═══════════════════════════════════════════════════════════════════════════════

Assumptions:
  - 10,000 monthly mobile visitors
  - Current: 5 MB per load
  - After: 1.5 MB per load
  - CDN cost: $0.085 per GB

BEFORE:
  10,000 users × 5 MB = 50 GB/month
  50 GB × $0.085 = $4,250/month in CDN costs
  User data cost: 10,000 × $0.40 = $4,000/month (developing markets)
  
AFTER:
  10,000 users × 1.5 MB = 15 GB/month
  15 GB × $0.085 = $1,275/month in CDN costs
  User data cost: 10,000 × $0.10 = $1,000/month
  
SAVINGS:
  Monthly CDN savings: $4,250 - $1,275 = $2,975
  Monthly user savings: $4,000 - $1,000 = $3,000
  Total monthly savings: $5,975
  Annual savings: $71,700
  
PLUS: Improved conversions (5-10% uplift) = $50,000-100,000
